# 家里 · 冰箱 / 衣柜 / 便签

记录家里的食材、衣物，以及那些「放在哪、什么时候要办」的小事。已发布成网站，可安装到手机/电脑桌面，断网也能打开。

- **线上地址**：https://yangjiqing1110-glitch.github.io/home-hub/
- **代码仓库**：https://github.com/yangjiqing1110-glitch/home-hub

## 四个模块

### 🧊 冰箱
- 分类：蔬菜 / 肉类 / 小吃 / 牛奶饮料
- 位置：**冷藏**或**冷冻**（卡片左上角标注，可按位置筛选）
- 状态：顶部「✓ 还有 / ✕ 没有了」两个标签自动分类；每张卡有快捷按钮「吃完了」，点一下就从「还有」移到「没有了」，在「没有了」里点「还有」又能放回去
- 每样东西都有配图：内置图标随便挑，也可以上传自己的照片（自动压缩后保存）
- 保质期：填日期后自动显示「还剩 X 天 / 今天到期 / 已过期 X 天」，并有一条新鲜度进度条
- 顶部横幅汇总「已过期 / 3 天内到期」，点「只看到期的」一键筛查
- 支持数量 + 单位、备注、搜索、排序（保质期 / 最近添加 / 分类）
- 每张卡都有「编辑 / 删除」，删除后 7 秒内可撤销
- 图标库覆盖常见中餐食材（蔬菜、肉类、水产、小吃、饮料……），也可以**自己贴任意表情**，或直接上传照片当图标

### 👕 衣柜
- 类别：上衣 / 裤装 / 外套 / 裙装 / 鞋履 / 配饰
- 记录季节、尺码、存放位置（挂杆 / 叠放 / 抽屉 / 收纳箱 / 鞋柜 / 衣架）
- 同样支持图标或拍照上传、备注、搜索

### 🍳 一周菜谱
- 周一到周日 × 早/午/晚三餐，点「＋ 点菜」从菜库里挑，也可以新建自己的菜
- 菜库自带 12 道家常菜（番茄炒蛋、咖喱鸡……），每道菜带食材
- 每道菜自动对照冰箱：**食材齐**（绿点）/**缺 N 样**（红点）/**有食材过期**（黄点），点菜时就能看到，标题还会汇总这一周缺几样
- 可翻上一周 / 下一周，排好的菜按日期保存，跟着同步码一起同步

### 📝 便签墙
- 便签可以选 5 种颜色，像贴在墙上一样轻微倾斜、带胶带和阴影
- 写「钥匙放哪、物业费几号交、洗衣机滤网怎么清」这类容易忘的事
- 可置顶、编辑、删除（删除后 7 秒内可撤销）

## 云同步（手机 + 电脑共用一份）

**默认就是同一个同步码**：任何设备打开这个网址，都会自动连到同一份云端数据，不需要填码。改动 1.2 秒后自动上传，打开或切回页面自动拉取，所以各平台看到的都是最新的一版。

页脚点「☁️ 已同步」可以：

- 看到当前同步码、上次同步时间，点「立即同步」手动拉取/上传；
- 看到**云端自动备份**：每 6 小时存一份快照（保留最近 10 份），可一键「恢复到这份」；
- 需要私密的话，可以「换成别的同步码」（换后该设备用私有码，其他设备仍用默认码）。

实现：Supabase 免费版 Postgres，`hub_state` 存最新数据、`hub_backup` 存快照，都按同步码分行并开启 RLS——请求必须带对 `x-household` 头才读得到，别的码看不到你的数据。

**注意**：默认同步码写在前端，拿到网址的人理论上也能读这份数据；只是网址没有公开列出来。介意的话换成自定义同步码，或把仓库设为私有（Pages 需付费）。

## 安装到桌面 / 手机

- 电脑：Chrome 地址栏右侧的安装图标，或页面左下角「📲 安装到桌面」；
- 安卓：Chrome 菜单 →「安装应用」/「添加到主屏幕」；
- iPhone：Safari → 分享 →「添加到主屏幕」。
装好后有独立图标、全屏打开，断网也能看已缓存的内容（数据仍是本机的，联网后自动同步）。

## 数据与备份

- 第一次打开是**空白**的，直接加自己的东西即可；旧版本留下的演示数据会自动清掉。
- 本机数据存在浏览器 `localStorage`（`homeHub.v1`），云端另有一份（自动同步 + 每 6 小时快照）。
- 右上角 **⬇ 备份** 导出 JSON（含同步码），**⬆ 导入** 恢复；页脚 **清空全部数据** 可以从零开始。
- 浏览器存储上限约 5MB；照片多时页脚会提示存储状态。

## 本地开发 / 重新发布

```bash
# 本地预览（任意静态服务器都行）
python -m http.server 8099 -d home-hub

# 重新部署到 GitHub Pages（需要 gh 已登录）
python tools/deploy_github.py
```

`deploy_github.py` 会：建/复用仓库 → 打包 `index.html sw.js manifest.webmanifest icons/` → 推送 → 开启 Pages → 等到构建完成并输出网址。
